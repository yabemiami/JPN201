19.1: Honorific Verbs and Hon. Verbal Constructions

Grammatical Construction:

{

  1. Some verbs have honorific counterparts: {0.7} {}.25 { |c|r|l| Regular & Honorific & *Irr. Conjugation
    いる/行く/来る & いらっしゃる (う) & いらっしゃいます
    みる & ご覧になる (う) &
    言う & おっしゃる (う) & おっしゃいます
    する & なさる (う) & なさいます
    たべる/のむ & 召し上がる (う) &
    くれる & くださる (う) & くださいます
    寝る & お休みになる (う)&
    〜ている_(注) & 〜ていらっしゃる (う) & いらっしゃいます
    } {0.2} (*the expected り is reduced as い)
  2. (注) -ている can turn into 〜ていらっしゃる
  3. お+V_STEMになる
    If there is an equivalent honorific verb, like the ones in (a), use it

}

Example

{

  1. 先生は おにぎりを お召し上がりになりました。
  2. 先生は 本を読んでいらっしゃる。
  3. 先生は お[すわり]になりました。

}

Note:

Honorific construction is not just polite. It honors/respects the subject of a sentence while ``polite'' means polite to the listeners.

19.2: Giving Respectful Advice

Grammatical Construction:

お+V_STEM+ください
It gives s.o. an advice to do s.th. with respect. However it is rarely used for an action that benefits the speaker directly (cf. d).

Example

{

  1. サンプルを お食べください。
  2. こちらで、お休みください。
  3. 名前を おかきください。(for the information the addressee seeks)
  4. {名前を 　 おかきください / かいてくださいませんか。(the speaker wants to talk to the addressee for his/her benefit)}

}

Note:

{

  1. N.B., it is not identical to V_て＋ください. お+V_STEM+ください is an advice. The speaker cannot be the beneficiary.
  2. very drastic ones like: お[たすけ]ください (Please save me!) works. (たすける/save s.o.)
  3. ご+V_STEM+ください happens with some the 〜する/になる expressions: [label={}.]
  4. ご注意ください (注意する)
  5. ご覧ください (ご覧になる)
  6. ご遠慮ください (遠慮する)

}

19.3: 〜てくれてありがとう = Thank you for V-ing

Grammatical Construction:

{ [T,onlytextwidth] {1} \[ \{ ... V_てくれてありがとう
... V_てくださってありがとうございます
\} = thank you for V-ing \] }

Example

{

  1. 手伝ってくれてありがとう。(for an assistance on a task)
  2. たすけてくれてありがとう。(for saving me from a crisis/danger/etc.)
  3. 手紙を読んでいただいてありがとうございました。

}

{

19.5: [_S ... V_PLAIN]＋はずです = supposed to be the case

Grammatical Construction:

{ [T,onlytextwidth] {1} \[ \{ [_S ... V_PLAIN]
[_S ... NPの]_Pres.Aff.
[_S ... ADJ_なな]_Pres.Aff.
\} ＋はずです = supposed to be the case \] }

Example

{

  1. メアリーは　アメリカに帰ったはずです。
  2. メアリーは もう 日本に戻らないはずです。
  3. たけしは アメリカに 行くはずです。
  4. あの人は 日本人のはずです。
  5. あの街は 静かなはずです。

}

Note:

{

  1. May not be conclusive but the speaker strongly believes/expects to be the case or it's a common believe. It is not used to express a duty, responsibility or law as English modals often ambiguously do: must/should: [label={}.]
  2. you must do it. (duty)
  3. you must be a spy. (belief)

}
