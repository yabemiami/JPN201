げ17.1: Pred.plain+そうです: I hear that ...

Grammatical Construction:
Vstem+そうです means 'It seems ...' (Lesson 13). We lean this time:
Vplain+そうです = `I hear that/It is said that ...'
Example
  1. ボブは アメリカに 帰るそうです
  2. ボブは アメリカに 帰らないそうです
  3. ボブは アメリカに 帰ったそうです
  4. ボブのクッキーは おいしいそうです
  5. ボブのクッキーは おいしくないそうです
  6. ボブのクッキーは おいしかったそうです
  7. ボブは げんきだそうです
  8. ボブは げんきじゃないそうです
  9. ボブは げんきだったそうです
  10. ボブは シェフだそうです
  11. ボブは シェフじゃないそうです
  12. ボブは シェフだったそうです
  13. ボブは アメリカに 帰りそうです
  14. ボブのクッキーは おいしそうです
  15. ボブは げんきそうです
  16. ボブは シェフの様ようです
Note:
Vplain+そうです is always stays そうです. Don't negate it or turn it into past tense.

げ17.2: Quoting with casual 〜って (= formal 〜と)

Grammatical Construction:
  1. Pred.Plainって ＝ Pred.Plainそうです = I hear that ... (not と)
  2. Pred.Plainって+言う/聞く/書く etc. (use と for writing)
Example
  1. ボブ: 今、忙しいです、昨日、寝られませんでした。だから、眠いんです。
  2. トム: 1. ボブは、今、忙しいって。昨日、寝られなかったって。だから、眠いんだって。
  1. 2-1 トムはパーティーに行くって言ってたよ。
  2. 2-2 ボブも行くって聞いたよ
  3. 2-3 ビルも行くって。
  4. 2-4 私も行くって書いておいてください。
  5. 2-4 メアリー行くって聞いたけど、来なかったよ。(next day)
Note:
〜って can embed direct quotes (verbatim) as well:
  1. ボブが、「絶対ぜったい来ます」って言ってたよ。
  2. 「私も必かならずずいきます」って書いておいてください。

げ17.3: [PredA〜たら] ... B./ If A, then B

Grammatical Construction:
  1. VerbA.Plain.Pastたら ... Pred.B = If A then, B
    (Event A has to happen before Event B)
  2. VerbA.Plain.Pastたら ... Pred.B = (If and) When A, then B
Example
  1. 田中さんを見たら、おしえてください。(If and when)
  2. 中国に行ったら、小籠包ショウロンポウを食べます。(If and when)
  3. 百万ドル(が)あったら、トラックを買います。(If - hypothetical)
  4. 私が猫だったら、テストはありません。(If - hypothetical)
  5. テストが終わったら、パーティーをしましょう。(When (it's not "if"))
Note:
NEVER: If, in the future A, then B now.(Event A has to have happened before Event B)
  1. NO テストがあったら、勉強しておいてください。
  2. VerbA.Plain.Pastたら ... Pred.B = (If and) When A, then B: B is often speaker's intention.
  3. the completed event in the main clause expresses a situation which is uncontrollable to the speaker. Thus, the main clause tends to express surprise or a realization (an unexpected event): i) お酒を飲んだら、吐いた。ii) 家に帰ったら、ドラえもんが いた

げ17.4: 〜なくてもいい/do not have to ...

Grammatical Construction:
Negative.Plain ないくてもいい(です)/ ... not have to ...
Example
  1. 読まなくてもいいです
  2. あつくなくてもいい
  3. きれいじゃなくてもいい
  4. 学生じゃなくてもいいですよ
  5. パスポートが なくてもいいですよ
  6. 子供の時、仕事を しなくてもよかったです
Note:
も of なくてもいい can be omitted in the casual speech:
  1. 読まなくていいです
  2. あつくなくていい
  3. きれいじゃなくてもいい
  4. 学生じゃなくていいですよ
  5. パスポートが なくていいですよ

げ17.5: 〜みたいです

Grammatical Construction:
  1. Noun+みたいです(なADJ): to resemble Noun
  2. Pred.plain+みたいです(なADJ): to appear to be the case that Pred
  3. です/な-Adj.Pres.Aff(=)+みたいです(なADJ): to appear to be the case that
Example
  1. あの人は山下先生みたいです。(1.)
  2. あの人は先生みたいです。(3.)
  3. 雨が降るみたいです。
  4. 雨が降ったみたいです。
  5. ボブは昨日、勉強しなかったみたいです。
  6. けんは日本に帰らないみたいです。
Note:
みたい is a な-adjective. It can be used as a relative clause:
  1. スーパーマンみたいです → スーパーマンみたいな人
  2. お母さんみたいです → お母さんみたいな人
  3. 人が住んでいないみたいです → 人が住んでいないみたいな家
  4. 雨あめが降ったみたいな部屋/a room that looks as if it rained (often hypothetical)
  5. 嵐が来たみたいにきたない部屋/ a dirty room that looks as if a hurricane came.

げ17.6: 〜前に/〜てから

Grammatical Construction:
  1. Verb.plain.present+前前に: before Verb
  2. Verbてから: Verb and then ...
Example
  1. 日本に来る前に、電話をしてください。
  2. 晩ご飯を食べる前に、宿題しゅくだいをしました。
  3. 日本に来てから、電話をしてください。
  4. 朝ご飯を食べてから、いきましょう。
Note:
Remember:
  1. 日本に来るとき、電話をしてください。/Call me when you come to Japan.
  2. 日本に来たとき、電話をしてください。/Call me when you have come to Japan.
Verb.plain.present+前前に sentences are pretty similar to (1). Verbてから emphasizes the [A and then B] event-order (unlike 2).
Expressions with 〜てから:
  1. くつをぬいでから、入ってください。(a required order)
  2. 映画を見てから、ボブにあった。(planned) vs. 映画を見た後あと、ボブにあった。
  3. 犬が死んでから、二年たちます。(a continued fact)
